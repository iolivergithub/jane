# Jane artwork

Original artwork made for Jane (October 2026). It is not derived from any stock art, photograph or font, and is covered by the same licence as the rest of this repository.

| File | What |
|---|---|
| `jane-logo-icon.svg` / `.png` (1024 px) / `-256.png` | Round badge: Jane in a green dress and brown riding boots |
| `jane-logo-wordmark.svg` / `.png` (2200×800) | Badge with "JANE / ATTESTATION ENGINE" |

The PNGs are rendered from the SVGs. The wordmark SVG draws "JANE" as shapes but the tagline as text, so its font depends on the viewer; use the PNG where the exact look matters.

The web UI favicon (`janeserver/services/webui/static/`) is generated from `jane-logo-icon.png`: `favicon.ico` (16, 32, 48, 64 px), `favicon-32.png` and `apple-touch-icon.png` (180 px).
