# Elements

An element is a description of something attestable.

The element consists of a set of its identifier, the compulsory description and a set of optional structures.


## Compulsory Fields

The compulsory fields are described below. The field *itemid* is generated by Jane and is a UUID4; this field should not be specified when adding a new element.

| Field | Type | Description |
| --- | --- | --- |
| itemid | UUID4 | Internally generated identifier |
| name | String | A short name for the element |
| description | String | A longer, more descriptive description |
| endpoints | Map of name to Endpoint | Where the element's trust agents are reached; see below |
| tags | String List | A set of freeform tags used for classification |

Each *Endpoint* has:

| Field | Type | Description |
| --- | --- | --- |
| endpoint | String | URL of the trust agent, e.g. `http://192.0.2.10:8530` |
| protocol | PROTOCOL | The [protocol](protocols.md) the trust agent speaks, e.g. `A10HTTPRESTv2` (tarzan) or `RATSD` |

An element may have several endpoints, e.g. tarzan and ratsd; each attestation names the one to use. jp creates elements from a provisioning file (see the [Quick start](quickstart.md)); they can also be created in the Web UI or over REST.


## Optional Fields
There are a number of individual structures to describe particular properties, eg: of TPMs, UEFI records etc.  Not all combinations are valid together, but this very much depends  upon the nature of the element in question.

### Host Machine
The following fields are part of the *host* entry; jp fills them in (`collecthostinfo`)

| Field | Type | Description |
| --- | --- | --- |
| os | String | The operating system of the host machine |
| arch | String | The CPU architecture of the host machine |
| hostname | String | The hostname |
| machineid | String | A unique identifier of a machine, typically /etc/machine-id as found in Debian and Ubuntu distributions |


### SSHKEY
The following fields are part of the *sshkey* entry

| Field | Type | Description |
| --- | --- | --- |
| key | String | The location of the private SSH key |
| timeout | Integer | The connection timeout limit in seconds |
| username | String | The username to log into the given account |

### UEFI
The following fields are part of the *uefi* entry

| Field | Type | Description |
| --- | --- | --- |
| eventlog | String | The location of the UEFI eventlog |

Note: the location specified here may be overridden by the behaviour of the trust agent

### Linux IMA
The following fields are part of the *ima* entry

| Field | Type | Description |
| --- | --- | --- |
| asciilog | String | The location of the Linux IMA log |

Note: the location specified here may be overridden by the behaviour of the trust agent


### Intel TXT
The following fields are part of the *txt* entry

| Field | Type | Description |
| --- | --- | --- |
| log | String | The location of the Intel TXT log |

Note: the location specified here may be overridden by the behaviour of the trust agent


### TPM 2.0
The following fields are part of the *tpm2* entry

| Field | Type | Description |
| --- | --- | --- |
| device | String | The location of the TPM2.0 device, eg: `/dev/tpmrm0` |
| ekcerthandle | String | The handle of the EK Certificate in the TPM NVRAM |
| ek | TPMKey | The structure describing the TPM 2.0 Endorsement Key |
| ak | TPMKey | The structure describing an attestation key |

The *TPMKey* structure is defined:

| Field | Type | Description |
| --- | --- | --- |
| handle | String | The persistent handle of the key in the TPM, e.g. `0x810100AA` |
| public | String | The key's public area: a marshalled TPM2B_PUBLIC, base64 (written by jp); used by rules such as `tpm2_validSignature` and by credential activation |
| name | String | The key's TPM name, hex (written by jp) |

## Example

An element as jp registers it (keys shortened):

```json
{ "itemid": "57c5a486-64ce-4563-b281-a743429c1617",
  "name": "Debian13VM",
  "description": "Debian 13 VM",
  "endpoints": {
    "tarzan": { "endpoint": "http://192.0.2.10:8530", "protocol": "A10HTTPRESTv2" }
  },
  "tags": [ "linux", "x86", "tpm2", "uefi" ],
  "tpm2": { "device": "/dev/tpmrm0",
            "ekcerthandle": "0x1C000002",
            "ek": { "handle": "0x810100EE", "public": "AToAAQALAAMAsg...", "name": "000bd126c6e1..." },
            "ak": { "handle": "0x810100AA", "public": "ARgAAQALAAUAcg...", "name": "000bbaff812d..." } },
  "uefi": { "eventlog": "/sys/kernel/security/tpm0/binary_bios_measurements" },
  "ima": { "asciilog": "/sys/kernel/security/ima/ascii_runtime_measurements" },
  "host": { "os": "linux", "arch": "amd64", "hostname": "debian13vm", "machineid": "39086971960e422aa636cb8bc7f1ad72" }
}
```
